# Paradise Nursery

A responsive online houseplant shopping application built with React, Vite, Redux Toolkit, and CSS.

## Features
- Landing page with a Get Started button
- Houseplants organized into categories
- Product images, names, and prices
- Shopping cart with add, increase, decrease, and delete actions
- Dynamic cart item count and price totals
- Checkout placeholder and Continue Shopping navigation

## Run locally

```bash
npm install
npm run dev
```

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- CSS
